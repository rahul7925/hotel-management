#  HotelHub

> **A Modern Hotel Management Application**
    (Hotel list Page)

---

##  Backend Architecture

**Node.js** | **Express.js** | **PostgreSQL**

---

##  Core Features

- **Hotel CRUD** - Complete management of hotel records.
- **Image Upload** - Seamless image processing and storage.
- **Search & Price Filtering** - Powerful dynamic querying.
- **Pagination** - Optimized data loading for large datasets.
- **Authentication** - Secure role-based access (Admin/User).
- **Hotel Details & Map** - Interactive location rendering.
